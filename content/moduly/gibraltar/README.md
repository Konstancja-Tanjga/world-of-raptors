# Moduł B3: Ptaki drapieżne Cieśniny Gibraltarskiej

Ścieżka B: Rozpoznawanie w terenie. Zobacz [plan kursu](../../PLAN-KURSU.md).

> Brama między Europą a Afryką. Kto przelatuje, jak go rozpoznać i gdzie stanąć, żeby go zobaczyć.

## Cele modułu
Po ukończeniu modułu potrafisz:
1. Wyjaśnić, dlaczego ptaki szybujące koncentrują się nad cieśniną i jak wiatr (Levante / Poniente) zmienia miejsce przelotu.
2. Rozpoznać w locie ok. 20 gatunków ptaków drapieżnych regionu — najpierw po sylwetce i sposobie lotu, potem po wzorze upierzenia.
3. Rozróżnić najczęściej mylone pary (np. trzmielojad / myszołów, jasny orzełek / ścierwnik, sęp płowy / sęp plamisty).
4. Zaplanować obserwacje: wybrać termin, punkt obserwacyjny i strategię zależnie od pogody.
